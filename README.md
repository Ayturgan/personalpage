# Ayturgan Karagulova — Personal Portfolio & Interactive Developer Dashboard

A premium, state-of-the-art developer telemetry dashboard and interactive personal website showcasing AI & Backend Engineering expertise.

🌐 Designed with **rich cyber-aesthetics**, utilizing deep black surfaces, elegant navy blueprints, and responsive crimson-red highlights, entirely optimized for readability, accessibility, and high performance.

---

## 🚀 Key Features

* **Developer Telemetry Dashboard**: Overhauled RPG mechanics to present backend APIs, LLM systems, and career progression with elegant, smooth-animating metric gauges.
* **Offline-First High-Fidelity Vector Icons**: Completely free of emojis and heavy third-party assets; utilizes custom inline vector SVGs that load instantly.
* **High-Contrast Interactive Terminal Logs**: Built-in mock shell allowing visitors to explore directory configurations, developer specs, and read system outputs.
* **Interactive Starfield Canvas Particle System**: Subtle stellar particles floating organically in the background, designed to minimize visual noise and maximize page readability.
* **Bi-lingual Interface**: Full-fledged support for Russian (`RU`) and English (`EN`) localizations.
* **Fully Responsive & A4 Printable**: Responsive CSS architecture looking stunning on ultrawides, mobile screens, and outputs a perfectly formatted print layout for PDF resumes.
* **Futuristic Audiovisual Toggles**: Embedded sound feedback system with quick visual controls to personalize user interaction.

---

## 🛠️ Tech Stack & Architecture

* **Core**: Vanilla HTML5, CSS3, and modern JavaScript (ES6+).
* **Canvas API**: Starfield simulation running on low-resource requestAnimationFrame callbacks.
* **Responsive Layouts**: Flexible grid systems and adaptive media queries.
* **Print CSS**: Complete print-optimized layouts for zero-waste paper rendering.

---

## 💻 Running Locally

Simply open the main file directly in any modern browser:

1. Clone this repository:
   ```bash
   git clone https://github.com/Ayturgan/personalpage.git
   ```
2. Navigate into the directory and launch `index.html`:
   ```bash
   # On macOS/Linux:
   open index.html

   # On Windows:
   start index.html
   ```
