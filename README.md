## 🚀 Featured Projects

- 🎬 **Faceless Shorts Pipeline**  
  Automated YouTube shorts pipeline for historical and science facts: script generation, narration prompts, voiceover steps, visual prompt packs, and repeatable faceless publishing workflows.

- 💸 **QR Payment Intermediary**  
  Web product built from scratch to simplify interbank QR payments, with backend validation and stability checks for 200+ concurrent users.

- 🏠 **Real Estate Aggregator**  
  Parsing-driven platform that collects fresh property listings from multiple sources and turns them into a searchable, unified feed.

- 🎲 **LLM Game Master Bot**  
  Interactive quest engine for branching stories and GM-led sessions with prompt orchestration, decision memory, session state, and replayable AI narratives.

- 🎮 **Yandex Games Mini Apps**  
  Mini apps and quiz games for Yandex Games, including a multi-difficulty The Last of Us trivia experience with progression logic.

- 🧠 **Second Dawn**  
  AI game prototype in Unreal Engine 5 with realtime TypeScript backend, WebSockets, NPC prompt architecture, short-term memory, and voice pipeline experiments.

- 🤖 **InfoCompanion**  
  Telegram bot for quick information lookup, translation support, and daily quotes packaged into a practical assistant flow.

- 🎨 **PixHarbor**  
  Gallery-style web app where users can upload photos, browse content, and interact through likes and comments.

- 💬 **Swiftalk Chat Application**  
  Realtime chat messenger prototype with product direction toward future wallet integration.

- 💰 **Zylocoin**  
  Product website for a Telegram crypto game ecosystem. Core gameplay code is confidential, but the shipped layer reflects fullstack and product work.
